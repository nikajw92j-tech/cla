# საქართველოს ბანკის API-ების დოკუმენტაცია

დოკუმენტაცია მანქანურად წაკითხვად ფორმატშია. ჯერ წაიკითხე, კოდის წერამდე:
მისამართები, პარამეტრების სახელები და ხელმოწერის წესები არ გამოიცნო.

## როგორ იმუშავო

1. წამოიღე გვერდების სია: https://api.bog.ge/docs/llms.txt
   თითოეულ ჩანაწერს მოჰყვება მოკლე აღწერა — აქედან აირჩიე საჭირო გვერდები.
2. წამოიღე მხოლოდ ის გვერდები, რაც დავალებას სჭირდება. ნებისმიერი გვერდის
   მისამართს დაამატე `.md` (მაგ. https://api.bog.ge/docs/payments/standard-process/create-order.md).
3. თუ მთელი დოკუმენტაცია ერთბაშად გჭირდება: https://api.bog.ge/docs/llms-full.txt
   (დიდი ფაილია — ჯერ ყოველთვის სცადე llms.txt.)

## რაზე მიაქციო ყურადღება

- გატესტე სავარჯიშო გარემოში, პროდაქშენზე გასვლამდე: https://api.bog.ge/docs/sandbox/payments/introduction.md
- `client_secret` არასდროს განათავსო კლიენტის მხარეს არსებულ კოდში.
- Callback-ის დამუშავებისას ხელმოწერა ყოველთვის გადაამოწმე — გადახდის სტატუსი
  მხოლოდ გადამოწმებული callback-იდან ან დეტალების მეთოდიდან აიღე.
- ღია ბანკინგის API-ები OpenAPI სპეციფიკაციებითაა აღწერილი; ბმულები
  llms.txt-ის ბოლოშია.
